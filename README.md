# Py.prompt
Hub desenvolvido em python com o objetivo de consolidar meus conhecimentos relacionados a programação e aprender mais conforme o desenvolvimento do projeto (obs: projeto alpha)

==sobre o script==

=========== Adendos importantes ============: 
- porte principal pra linux. nao desenvolvido, ainda, o porte pra windowns nem mac (dificilmente havera pra MAC) 
– Inquirer py nao é uma preferência, é necessário para que nao haja bugs. então, antes de instalar, tente: pip install inquirer
=============================================


Menu interativo – desenvolvido em inquirer.py- que possui:
* pedra papel e tesoura
* organizador de arquivos 
* Criador de tarefas. 

- Relacionado ao pedra papel e tesoura, jogo simples a qual você so precisa movimentar o menu interativo e baseia seu resultado na sorte. 

- Em consideração ao organizador de arquivos, ele esta em modelo pré-alpha para mais pesquisas futuramente. Ele analisa a pasta dowloads e cria pastas que filtram cada arquivo analisado. exemplo: arquivo imagem .png, caso nao haja a presença de pasta ele cria uma. 

- em consideração as tarefas, basicamente ela possui algumas ações, sendo elas: listar suas tarefas, criar uma tarefa, excluir uma tarefa e sair. para criar uma tarefa basta somente você escrever a posição e a tarefa de sua necessidade. na exclusao so precisa falar a posição selecionada:
obs: é de preferencia que você faça 1, 2, 3 ou 4, entretanto isso é baseado em sua escolha e memória.
